# ELML IDE (官方实现)

这是 ELML (极简脚本语言) 的官方执行引擎和编辑器，基于 Visual Basic 6.0 编写。

>**注意**：关于 ELML 的完整语言规范和教程，请访问 [ELML 官方文档仓库](https://github.com/copyleftcat/ELML-Docs)。

## 特性
- 极简的基于 `{}` 的语法
- 内置 `Let` 变量声明与 `MsgBox` 输出
- 极简的复古 UI 界面

## 如何编译
1. 下载并安装 Visual Basic 6.0。
2. 克隆本仓库，双击 `Project1.vbp` 打开工程。
3. 按 `F5` 运行，或通过“文件 -> 生成 EXE”编译。
